# Run 001 结果总结

Level 0 Minimal TF / Equilibrium Characterization

日期: 2026-05-18 | 分支: `learnability-level0-implementation`

---

## 1. 核心现象：大部分轨迹呈周期性振荡

在默认参数范围（rho: 0.5~2.0, δp: 0.05~0.3）下运行 20 个 world（每 world 3 个 cell），观察到：

- **仅 6/20 world（30%）收敛至稳态**。其余 14 个 world 的所有 cell 均呈现持续的周期性振荡。
- **所有 20 个 world 均为 bounded**（无发散），无 collapse。
- 振荡的根源是 TF 子图中存在一个 3 节点负反馈环：`TF2 → TF0 → TF1 ⊣ TF2`，当 feedback gain 过高时，阻尼不足以压制信号的自激循环。

参见 P_traj_page*.png（plots/default/ 及各 sweep 目录下），converged 的 cell 在标题中标注为 `(converged)`，否则标注为 `(unconverged)`。

---

## 2. 振荡原因分析

### 2.1 图拓扑

所有 world 共享同一张调控图（seed=1000），包含 4 个 TF 和 16 个 target 基因。TF 子图结构：

```
TF0 ← TF2 (activation)
TF1 ← TF0 (activation)
TF2 ← TF1 (repression)  ← 三节点环路中唯一的负边
TF3 ← TF2 (repression)
```

三节点环路 `TF2 → TF0 → TF1 ⊣ TF2` 是系统的振荡核心（两正一负，奇数条负边构成负反馈环）。每次循环经历 3 步信号传递，若增益足够大，抑制解除后新一轮上升立即开始，形成节律性振荡。

### 2.2 参数因素

振荡与否取决于 TF 环路上 feedback gain 的大小，即 **effective drive = γ·ρ/(δx·δp)**。默认参数范围下：

| 参数 | 默认范围 | 问题 |
|------|---------|------|
| rho | 0.5 ~ 2.0 | 上限过高，转录驱动力太强 |
| δp | 0.05 ~ 0.3 | **下限太低**（0.05 意味着蛋白半衰期 ≈14 步），反馈信号在环路上停留太久 |
| δx | 0.1 ~ 0.5 | 影响较小（mRNA 周转快） |
| K | 1.0 ~ 5.0 | 影响较小 |

**关于 K 的取值范围**：原版 ddc（Phase 0）中 K 为 `uniform(0.1, 1.0) / G ≈ 0.002~0.02`，极小值意味着 TF 浓度稍有上升即可饱和 Hill 响应，调控极为灵敏。当前 ddc_lite 未沿用它，而是采用 K ∈ [1.0, 5.0]。也就是说，TF 蛋白浓度需累积到较高水平（超过 K≈3）才能进入 Hill 函数的非线性饱和区——这会显著影响动力学行为的时间尺度和振幅特征，是导致观察到的振荡轨迹中蛋白缓慢攀升的重要背景因素。

### 2.3 关键证据

逐一核查不收敛 world 的 TF 基因级 δp，发现规律：凡是不收敛的 world，其 TF 环路中至少有一个关键节点的 δp 抽到了极低值。例如 W1000 的 TF1 δp=0.05、TF0 δp=0.066，这两个 TF 恰是激活链上的节点（TF1 由 TF0 激活），降解极慢导致激活信号在环路中持续驻留。相比之下，收敛 world（如 W1008）的 TF0 δp=0.216、TF1 δp=0.109，明显更高。即使在组合扫描中抬高了 δp 下限（0.1），剩余不收敛的 6 个 world 中仍有 TF δp 仅 ~0.10 的个例，配合非微小 rho，局部 drive 仍过高。

## 3. 参数扫描实验

为验证上述分析，在固定调控图前提下，对 4 组参数范围进行了对比扫描：

| Sweep | rho 范围 | δp 范围 | 其他参数 |
|-------|---------|---------|---------|
| default | 0.5 ~ 2.0 | 0.05 ~ 0.3 | K: 1.0~5.0, δx: 0.1~0.5 |
| rho0.2-0.8 | **0.2 ~ 0.8** | 0.05 ~ 0.3 | 同上 |
| dp0.1-0.4 | 0.5 ~ 2.0 | **0.10 ~ 0.4** | 同上 |
| rho0.2-0.8_dp0.1-0.4 | **0.2 ~ 0.8** | **0.10 ~ 0.4** | 同上 |

---

## 4. 扫描结果

| Sweep | 收敛率 | 收敛 world 数 | 平均收敛时间 | mean drive (conv) |
|-------|:------:|:------------:|:----------:|:------------------:|
| default | 30.0% | 6 / 20 | 128.1 | 24.1 |
| rho0.2-0.8 | 55.0% | 11 / 20 | 117.4 | 9.6 |
| dp0.1-0.4 | 35.0% | 7 / 20 | 106.7 | 16.4 |
| **rho0.2-0.8_dp0.1-0.4** | **70.0%** | **14 / 20** | 94.9 | **6.8** |

### 4.1 降 rho 的效果

rho 从 0.5~2.0 压到 0.2~0.8 → 收敛率 +25%（30%→55%）。rho 控制信号的放大强度，降低 rho 直接削弱 feedback gain。

### 4.2 抬 δp 的效果

δp 从 0.05~0.3 抬到 0.1~0.4，T=200 时仅 +5%。原因是蛋白降解加快后需要更长模拟时间才能收敛。但从 mean drive 看，抬 δp 确实压低了有效增益（24.1→16.4）。

### 4.3 双参数联合的效果

rho 0.2~0.8 + δp 0.1~0.4 → 收敛率 **70%**，mean drive 降至 6.8。从两端同时压低 effective drive，效果最好。

### 4.4 剩余 6 个顽固不收敛 world

即使在组合扫描下，W1000、W1001、W1007、W1010、W1013、W1014 仍振荡。它们的共同特点：TF 子图中关键激活节点的 δp 仍偏小（~0.10），且 rho 非微小。

---

## 5. 主要发现

1. **沿用原 ddc 的默认参数范围不可行**。该范围下 70% 的 world 呈持续周期性振荡，无法用于下游的 equilibrium-based 分析。

2. **Effective drive = γ·ρ/(δx·δp) 是最具区分力的指标**。跨 sweep 对比：drive 越低，收敛率越高（24.1→9.6→6.8 对应 30%→55%→70%）。

3. **仅降 rho 或仅抬 δp 均不够**。前者仅达 55%，后者在 T=200 时仅达 35%。需要更短的蛋白半衰期配合更低的转录驱动，才能稳定地压制环路振荡。

4. **30% 的系统即使不收敛也不发散**——全部 bounded，无 collapse。说明当前动力学是 "marginal oscillator"，能量既不爆发也不消失，只是在反馈环中循环。

## 6. 下一步计划

### 6.1 必须开展更系统的参数搜索

当前沿用的原 ddc 参数默认范围必然导致周期性振荡，不可直接使用。下一步应在以下两个维度上做更精细的扫描：

- **rho 下限进一步降低**：尝试 rho 0.1~0.5
- **δp 下限进一步提高**：尝试 δp 0.15~0.5（蛋白半衰期 ≤5 步）

目标是找到能稳定产生 >80% 收敛率的参数组合，而非停留在 70%。

### 6.2 探索不同 repression ratio 的影响

当前所有 world 共享同一张图，repression_ratio 固定为 0.50（20 条边中恰好 10 条抑制）。在 Phase B（graph resampling）中，应在已识别的 stable parameter regime 下，系统地改变 repression_ratio（如 0.3 / 0.5 / 0.7），观察：

- 抑制比例升高是否抑制振荡
- 不同 repression_ratio 下，同样的参数是否仍能收敛
- 是否存在 "activation-dominated 图需要更强阻尼" 的规律

### 6.3 延长模拟时间

对于 dp0.1-0.4 sweep，T=200 明显不足。建议后续对高 δp regime 使用 T=400~500，避免因时间不足误判收敛。

### 6.4 更新收敛检测逻辑

当前 eps=0.01 对缓慢收敛系统可能偏严。后续可考虑采用末尾窗口的相对变化率（而非绝对 L2 范数），更好地区分 "缓慢收敛" 与 "持续振荡"。
