# 2.4 Regulatory Graph (Phase 0)

## A. Transcription Graph

Only TF genes can appear as transcription regulators.

For each gene $i$:
$$
d_i \in \{1,2,3\},
\qquad
\mathbb{P}(d_i = k) = \frac{1}{3}
\quad \forall k \in \{1,2,3\}
$$

- Sample $d_i$ distinct TF regulators uniformly without replacement.
    
- If $i$ is a TF, self-regulation is not allowed.
    
- Graph is fixed per run.
    
Let $\mathcal{T}$ denote the set of TF genes.

Regulators are sampled from:

- $\mathcal{T} \setminus \{i\}$ if $i \in \mathcal{T}$,
- $\mathcal{T}$ otherwise.

Sampling is performed uniformly without replacement.

---

## B. Chromatin Graph

For each gene $i$:

- Select exactly 2 epigenetic modifier genes.
    
- These define the set $E(i)$.
    
- Graph is fixed per run.

# 5. Monte Carlo World Rule

Each simulation run:

1. Sample regulatory graphs.
    
2. Sample parameters.
    
3. Initialize state variables.
    
4. Simulate for $t=1,\dots,T$.
    
5. Store full trajectory.
    

---

# 6. Reproducibility

- All randomness must use a single RNG instance.
    
- Each run must record:
    
    - seed
        
    - graph structure
        
    - parameter values
        

Re-running with the same seed must reproduce identical trajectories.

> Phase 0 run initializes a **single cell**.  
> Multi-cell datasets are generated by the population wrapper (Section 7).

---

# 7. Population Sampling Interface (scRNA-ready)

Phase 0 simulates a single-cell dynamical trajectory:

$$  
(X(t), P(t), Z(t))  
$$

under a fixed world (graph + parameters).

To generate scRNA-seq–like datasets (e.g., 5,000–50,000 cells), we introduce a population wrapper.

In Phase 0, the default observation model is:

$$
C_c(t) = X_c(t)
$$

unless an explicit noise or sampling model is activated in later phases.

---

## 7.1 Two-level Randomness

### World-level (sampled once per run)

- Regulatory graphs
    
- Parameters
    
- Run-level latent context
    

### Cell-level (sampled per cell)

- Initial conditions
    
- Observation noise
    
- Sampling depth
    
- Optional nuisance factors (Phase 1+)
    

---

## 7.2 Minimal Multi-cell Generator (Phase 0)

For a fixed world $W$:

For $c = 1,\dots,M$:

1. Sample cell seed.
    
2. Sample initial state $S_c(0)$.
    
3. Simulate trajectory $S_c(t)$ using world $W$.
    
4. Generate observed output $C_c(t)$ from $X_c(t)$.
    

Dataset dimensions:

- Cells: $M$
    
- Genes: $G$
    
- Time points: optional subset of $t$
    

> All cells in the same dataset share the same world.
